# 运行截图清单

> 报告要求“附加部分运行界面和主要代码”。本清单给出建议拍摄的界面与检查点，截图后插入实验报告第五节。
> 本项目未提交任何本机截图，避免使用与本人设备不符的图片。

## 一、准备运行环境

1. 用 Android Studio 打开 `LanTianhaoBookManager` 目录，等待 Gradle 同步。
2. 打开 **Tools → Device Manager**，创建或启动一个 API 33 的模拟器（Pixel 系列即可）；也可以连接 Android 7.0 以上真机并开启 USB 调试。
3. 点击 Run，或执行：

```bash
# Windows
gradlew.bat installDebug

# macOS / Linux
./gradlew installDebug
```

4. 确认首页标题为 **兰天浩2024110515**，列表价格从 ¥22.00 开始递增。

## 三、截图注意事项

- 截图需包含手机状态栏或模拟器边框，便于老师判断是实际运行界面。
- 至少提交 **首页列表、详情页、搜索或收藏、关于/深色模式** 四类界面。
- 报告中的主要代码建议截取：
  - `BookRepository` 中的 `Book[]` 数组；
  - `BookSorter` 的价格升序 `Comparator`；
  - `MainActivity#openDetail()` 的 `Intent` 跳转；
  - `colors.xml` 中的蓝色定义与 `themes.xml` 的全局文字颜色。
- 若使用模拟器，可直接点击模拟器工具栏的相机图标截图；真机可使用系统截屏后传到电脑。
