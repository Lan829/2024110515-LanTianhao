```kotlin
data class Book(
    val title: String,        // 书名
    val author: String,       // 作者
    val publisher: String,    // 出版社
    val price: Double,        // 价格
    val isbn: String,
    val category: String,
    val publishYear: Int,
    val rating: Float,
    val description: String
) : Serializable {
    val initial: String
        get() = if (title.isEmpty()) "书" else title.substring(0, 1)

    // 以 ISBN 重写 equals / hashCode
}
```

### 4. 按价格从低到高排序

使用 `Comparator` 先比较价格，再以书名作为第二关键字，保证价格相同时顺序稳定。

```kotlin
val byTitle = Comparator<Book> { first, second ->
    String.CASE_INSENSITIVE_ORDER.compare(first.title, second.title)
}
val byPriceAsc = Comparator<Book> { first, second ->
    first.price.compareTo(second.price)
}.thenComparing(byTitle)
books.sortWith(byPriceAsc)
```

### 9. 拓展功能核心代码

**搜索与收藏组合筛选：**

```kotlin
@JvmStatic
fun filter(
    books: List<Book>,
    query: String?,
    favoritesOnly: Boolean,
    favoriteIsbns: Set<String>?
): List<Book> {
    val keyword = query?.trim()?.lowercase(Locale.ROOT).orEmpty()
    return books.filter { book ->
        (!favoritesOnly || favoriteIsbns?.contains(book.isbn) == true) &&
            (keyword.isEmpty() || matches(book, keyword))
    }
}
```

**统计信息：**

### 4. 遇到的问题与解决

1. **列表排序与筛选冲突**：切换排序或搜索后需要保持当前筛选条件。将排序、搜索、收藏过滤统一收敛到 `applyFilters()`，每次先过滤再排序，逻辑清晰且不会互相覆盖。
2. **详情页收藏后列表不同步**：详情页修改收藏后返回列表，星标未刷新。利用 `onResume()` 重新读取 `FavoriteStore` 并调用 `refreshFavoriteMarks()` 刷新可见项。
3. **旋转屏幕状态丢失**：在 `onSaveInstanceState()` 中保存搜索词、排序方式和“只看收藏”状态，重建后恢复。
4. **收藏集合读写引用问题**：`SharedPreferences.getStringSet()` 返回的集合不应直接修改，统一复制到新的 `HashSet` 后再操作。
