【实验一 多语言 Hello World —— 提交到你的 GitHub】

■ 一、在 GitHub 上新建仓库
  登录你的 GitHub → 右上角 "+" → New repository
  → Repository name 随便起（例如 HelloWorldApp）→ 选 Public → Create repository

■ 二、用 Android Studio 打开本项目
  Android Studio → Open → 选择本文件夹（含 build.gradle 的那层）

■ 三、在 Android Studio 底部 Terminal 里依次执行：
  git init
  git add -A
  git commit -m "实验一 多语言 Hello World"
  git branch -M main
  git remote add origin https://github.com/你的用户名/你的仓库名.git
  git push -u origin main

■ 四、push 时若要求登录
  用户名填你的 GitHub 用户名；
  密码处粘贴 Personal Access Token
  （GitHub 不再支持账号密码，需到 Settings → Developer settings → Personal access tokens → Tokens(classic) 生成，勾选 repo）

■ 五、成功后你的仓库地址为：
  https://github.com/你的用户名/你的仓库名
  把这个地址填进实验报告里的「Gitee网址」那一栏（按老师要求）
